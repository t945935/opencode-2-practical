# L03 批次整理問題並建立待辦

狀態：模型實測通過。對應書籍第 05 章，主題：Code Mode。

## 前置條件

本機測試 MCP server、虛構問題資料與測試待辦儲存區。

## 任務提示草案

> 讀取問題清單，檢查既有待辦，僅建立缺少的項目，回報對照表。

提示只是任務說明，實際流程仍需完成前置設定與章節步驟。

## 預定交付

問題 ID 與待辦 ID 對照、去重後資料。

## 完成判準

第二次執行不新增重複項目；有實際 MCP 呼叫紀錄。

## 失敗與復原

為每個問題保留穩定 ID，重跑前先查既有紀錄。
