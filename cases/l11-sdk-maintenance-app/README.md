# L11 嵌入維護請求處理器

狀態：model_success_verified_cancellation_pending。對應書籍第 09 章，主題：SDK。

## 前置條件

指定 SDK 版號、本機測試工作區、小型入口程式。

## 任務提示草案

> 將維護描述交給嵌入式 host，顯示執行狀態並產出待審查的修改。

提示只是任務說明，實際流程仍需完成前置設定與章節步驟。

## 預定交付

可啟動應用、變更差異、事件紀錄。

## 完成判準

host 可建立、事件可讀、完成可辨認，關閉不遺留執行資源。

## 失敗與復原

保留每次請求識別碼；失敗時關閉 host 並還原練習資料。

## 測試範圍

本機應用；不預設部署到公網。精確工具版號、模型與目前結果見版本狀態；未列出的延伸尚未驗證。
