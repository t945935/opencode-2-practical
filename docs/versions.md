## 本輪修正

部署外掛改為 `plugins/deployment/index.js`，設定指向目錄。2.0.30 的明確本機外掛路徑以此方式實測成功。TUI 來源改用 `tui.tsx` 專用入口，尚未據此宣稱畫面通過。

SDK 預設記憶體資料庫沒有帶入專用 CLI 資料庫的登入。設定 `ISSUEDESK_DATABASE` 指向自己的既有練習資料庫，並明確指定 `ISSUEDESK_MODEL` 後，模型流程成功。請勿分享登入資料庫。

早期免費模型認證失敗、外掛未載入及 SDK no-route 留在作者驗證紀錄；本表描述修正後範圍。完整模型紀錄不公開，下載庫只提供去除私人環境資訊的摘要。
