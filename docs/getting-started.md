# 開始使用

目前可先下載素材、閱讀案例目標及熟悉任務卡；完整程式碼與章節操作會在正式配套完成後加入。現在不需要安裝任何套件來閱讀這些 JSON 與 Markdown。

## 建立練習副本

將本庫下載到自己的目錄，另外建立練習資料夾，複製 fixtures 與需要的 templates。保留一份未修改的下載包供對照。不要把私人專案作為第一次練習起點。

## 基本素材

- issues.json：六筆虛構問題，有狀態、嚴重性與標籤。
- errors.json：八筆虛構錯誤，使用 issue_id 關聯已知問題；null 表示尚無關聯。
- task-card.md：輸入、範圍、成果與驗收。
- verification-record.md：記錄版本、步驟、結果與費用。
- prompts.md：準備階段通用提示草案。

後續需要模型帳號的操作可能產生費用；各章將記錄前置條件。OpenCode 安裝依[官方 V2 文件](https://opencode.ai/v2/docs/)，本配套目前未指定已測版本。
